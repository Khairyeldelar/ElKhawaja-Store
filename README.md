# ElKhawaja Store | الخواجة ستور

Flutter storefront application reconstruction from the original archived project.

## Original application
- Flutter and Dart
- Firebase Authentication, Cloud Firestore and Firebase Storage
- BLoC state management
- Product listing, details, create/edit and account screens
- Categories: watches, pens, rosaries, incense, gemstones and others
- Arabic and English translations

## Status
Repository initialization only. Original application source, assets, and platform files have **not yet been uploaded**. Do not treat this repository as buildable.

## Security
Signing keys, certificates, private configuration, local machine settings, and Firebase credentials must never be committed.

## Compatibility
The archived project targets Dart >=2.16.1 <3.0.0 and uses older FlutterFire packages. Verify dependencies before building with modern Flutter.
